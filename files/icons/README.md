# Application icons

Source: Simple Icons 11.15.0 (https://github.com/simple-icons/simple-icons/tree/11.15.0).
SVG files use brand-color fills and are stored locally to avoid runtime CDN dependencies.
See LICENSE.md for the upstream CC0 license. Brand names and logos remain the
property of their respective owners; inclusion does not imply endorsement.

The gallery's inline play/pause controls and installer download links use Lucide icons.
See LUCIDE-LICENSE for their license.

`app-installer.png` is an original generated application icon, not a Simple Icons
asset. Its source and generation prompt are documented in
`launcher/assets/app-installer-icon.md`.
