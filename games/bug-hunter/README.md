# バグハンター

Unity 6.0.54f1 製の3D探索・捕獲・育成・指示式バトルのプロトタイプ。
企画書 `../../files/mushi-shooting.pdf` とユーザーの追加仕様を元にした実装です。
正本はこのフォルダーです。Switch向けのビルド・認証は含みません。

## 開く

Unity Hub からこのフォルダーを追加し、`Assets/BugHunter/Scenes/Woodland.unity` を開いて Play。
6種の虫は `Assets/BugHunter/Species` の ScriptableObject で能力・成長・技・見た目を編集できます。
モデルは `Assets/BugHunter/Generated` の共有メッシュとPrefabです。
既存シーンがある場合、初期化コマンドは上書きしません。

## 遊び方

- 探索：WASDで移動、右ドラッグで視点、Spaceで捕獲。画面内にも方向・捕獲ボタンがあります。
- 虫に近づいて狙いを合わせると集中ゲージがたまります。捕獲の成功率が上がります。
- 虫かごで個体ごとの体力・攻撃・防御・素早さと成長量を比較し、パートナーを選びます。
- 育成は樹液8で経験値36。捕獲や試合で樹液を得ます。レベル上限は20。
- 戦闘では1＝攻撃、2＝防御、3＝技。接近・攻撃動作は自動で、指示を繰り返します。
- 防御はダメージ軽減と体勢・スタミナ回復。技は高威力ですが消耗と転倒リスクがあります。
- 練習試合と3連戦の大会。勝敗に応じた経験値・樹液、大会優勝でトロフィーを得ます。
- ローカル自動保存。Web版は同一ブラウザー・同一サイトの保存領域を使用します。

## 個体差と転倒

同種でも初期能力、成長量、性格、サイズが異なります。個体生成はseedから再現可能。
タイプはパワー → ガード → スピード → パワーの三すくみで、有利1.16倍、不利0.9倍。

転倒判定には攻撃の種類、体勢、疲労、防御と乱数を使います。1回の被弾での転倒率は最大34%。
転倒中は防御無効・被ダメージ1.35倍。約3.4〜4.6秒で起き上がり、その後3秒は再転倒しません。
追撃でダウン時間は延長されません。大技の使用者にも低確率で体勢を崩すリスクがあります。
試合には150秒の上限があり、残り体力の割合で判定します。

## ビルドと検証

UnityのWeb Build Supportが必要です。Editorメニュー `Bug Hunter/Build Web` または
`-batchmode -quit -buildTarget WebGL -executeMethod BuildGame.Web` でビルドします。
出力先は `BUG_HUNTER_BUILD` 環境変数、未指定なら `Builds/Web`。
`BuildGame.Validate` は初期化・コンパイル後のルール検証を行います。
`node tools/prepare-bug-hunter.cjs <Webビルド出力先>` をリポジトリ直下で実行すると
Webライブラリへ反映します。既存5作品とWindows版は変更しません。

WindowsのIL2CPPツール用に `%TEMP%/bug-hunter-unity` というASCII名のジャンクションから
正本を開いています。これは複製フォルダーではありません。削除する際はリンクだけを削除し、
リンク先の正本を再帰削除しないでください。

## 軽量化方針

- 6種の共有ローポリメッシュと頂点カラー。モデルごとの大きなテクスチャは使用しません。
- 簡潔な3段階トゥーンシェーダーと共有マテリアル。リアルタイム影・ポストエフェクトなし。
- フィールドの木・草・地形はまとめたメッシュ。描画物を毎フレーム生成しません。
- 虫はフィールドに18匹。捕獲後は既存オブジェクトを再利用して復活します。
- Webの初期WASMヒープ64MiB、必要時16MiB単位で増加、上限256MiB。
- 描画解像度はCSS表示サイズ、devicePixelRatioは1。約60fpsを目標に画面更新に同期。
- Web版では画面更新間隔を測定し、高リフレッシュレートの環境でも不要な描画を抑制します。
- 日本語フォントは再配布可能なNoto Sans JP。大きな動画・環境画像・音源は同梱しません。

実機測定前の予算設定であり、全端末でのメモリ量やフレームレートを保証する値ではありません。
Webの `window.__bugHunterStats` は画面状態・割当メモリなどの読み取り専用診断値です。
