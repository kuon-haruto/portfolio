# Application Icon

Original dedicated icon generated with the built-in ImageGen tool on 2026-09-26.
Source asset: `app-installer.png`. Transparent padding is preserved. Windows icon
sizes are generated by electron-builder from this PNG; no game artwork is reused.

Prompt:

> Use case: logo-brand. Create ONE original Windows desktop application icon for a Japanese game launcher named アプリインストーラー. Output a square 1024x1024 bitmap icon, not a presentation or mockup. No text, letters, numbers, captions, watermarks, or existing game artwork. The distinctive central symbol should combine a bold ivory game controller silhouette with a clearly readable mint-teal downward download arrow / open library tray, suggesting a collection of games ready to play. A small coral accent may distinguish it. Very simple large geometric forms, crisp polished edges, near-flat professional app branding with subtle depth, legible at 32px. Charcoal backing tile, gently rounded square corners, centered with even narrow padding, transparent canvas outside the tile. Avoid excessive detail, thin lines, neon glow, purple, busy backgrounds, screenshots, or multiple alternate icons. This is the launcher's own icon, not the icon of any individual game.
